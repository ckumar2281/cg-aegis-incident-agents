What to point at

NodeWhy it is there
quarantine → triageContainment is attempted on every incident, before any agent runs. When there is no file the node says so and moves on — the graph never decides whether to try.
triage → 4 specialistsOne superstep, four agents concurrently. Each reads different data and answers a different question.
rca ⇢ round_twoThe loop. When confidence is short, fresh directives go back to the specialists — bounded at two rounds.
plan ⇢ autonomousThe autonomy ladder as real control flow. Low-risk reversible work skips every gate.
disclose ⇢ business_gateThe redaction firewall sits between them. A failed check routes to disclosure_failed, not onward.
business_gate ⇢ technical_gateTiered disclosure: the technical packet is only released once the business gate approves.
business_gate ⇢ rejectedThe human can say no, and the system obeys — file stays held, ticket raised, nothing executed.
The dashed edges are where the decision is computed, not configured. That is the difference between a multi-agent system and a pipeline of function calls: the graph does not know in advance which way it will go.
